# 面板截图与介绍建议

这个文件用于指导你在 GitHub README 中放哪些截图，以及每张截图应该展示什么内容。

## 截图建议

建议准备 4 张截图，放到：

```text
docs/images/input-output.png
docs/images/compose-guard.png
docs/images/results.png
```

## 1. 输入输出面板

建议截图内容：

- 推荐分档
- B 主视频选择区域
- A 素材队列
- 输出目录
- 生成预览
- 视频体检
- 断点续跑
- 画质不佳自动重试

介绍重点：

- 这是工具的任务入口。
- B 主视频是最终画面主体。
- A 素材可以多个，用于合成层。
- 先预览再批量处理，降低返工成本。

## 2. 合成保护面板

建议截图内容：

- A/B 合成策略
- 透明通道工作流
- 运动感知保护
- B 主画面保护
- 暗水印写入与检测

介绍重点：

- 推荐使用隐形融合。
- 高速运动画面中会自动降低 A 层干扰。
- B 质量守门用于保护输出观看体验。
- 暗水印检测用于确认写入结果。

## 3. 配置策略

不建议在公开仓库展示过于具体的高级参数页。README 中可以只说明工具内置推荐配置，并支持在特殊素材下进行必要调整。

介绍重点：

- 普通用户优先使用推荐分档。
- 高级设置用于特殊素材下的细节调整。
- 完整处理前建议先生成预览。

## 4. 任务结果面板

建议截图内容：

- 任务明细表
- 视频体检报告
- 参数差异摘要
- 运行日志
- 打开输出目录
- 清理临时文件

介绍重点：

- 可以看到每个任务的状态和进度。
- 可以查看水印检测结果和画质指标。
- 失败时可以通过中文日志排查原因。

## 截图注意事项

- 不要展示客户素材。
- 不要展示隐私文件路径。
- 不要展示账号、手机号、微信二维码原图或密钥。
- 如果截图中有真实视频画面，建议打码或使用测试素材。
